1. 핵심 요약 및 2026 시장 지표

기준 시점: 2026년 11월 25일 (공식 블로그·가격표·투자 발표 기준)

2025~2026년 개발 플랫폼 시장은 사람이 대시보드를 클릭해 서버를 띄우던 시대에서 AI 코딩 에이전트가 코드 작성, DB 프로비저닝, 샌드박스 테스트, 프로덕션 배포까지 자율적으로 수행하는 에이전트 중심 인프라(Agentic Infrastructure) 시대로 전환되었습니다.

80% 스타트업 Postgres 채택률 Supabase State of Startups 2026 기준 (Supabase 49% + Postgres 22% 등)
80%+ Neon 에이전트 자동 생성 DB 인간이 아닌 AI 에이전트가 API로 프로비저닝한 비중
$15.75B Modal 기업가치 (2026.10) ARR $10억 돌파, 전년 대비 15배+ 성장
28배 Vercel 에이전트 배포 증가 최근 12개월 에이전트 트리거 배포 성장률 (Ship 2026)
2026년 3대 핵심 결론

첫째, 에이전트가 인프라를 직접 조작하기 위해 MCP(Model Context Protocol), 브랜치 격리 DB, 일회용 샌드박스가 모든 플랫폼의 기본 기능이 되었습니다. 둘째, 유휴 대기 시간을 과금하지 않는 Active CPU·초당 종량제 모델이 표준으로 자리 잡았습니다. 셋째, Databricks의 Neon 인수($1B), Google의 Wiz 인수($32B), Supabase의 Turso 인수(2026.10) 등 데이터·보안·에이전트 레이어를 수직 통합하는 대형 M&A가 잇따랐습니다.

2. 2025~2026년 8대 거시 트렌드

공식 발표 및 시장 조사 데이터 기반

왼쪽 차트는 2025~2026년 공개된 주요 개발·보안 플랫폼의 기업가치 및 인수 규모(단위: 십억 달러)이며, 오른쪽은 Supabase State of Startups 2026 조사의 주력 데이터베이스 점유율입니다. Postgres 계열이 80%까지 확장된 반면 MongoDB(-5%p), MySQL(-3%p), Firebase(-2%p) 등 기존 선택지는 점유율이 하락했습니다.

트렌드 01

핵심 동인

AI 네이티브·바이브 코딩이 백엔드와 DB 수요를 견인

Supabase 조사에서 스타트업 61%가 코드의 절반 이상(40%는 76~100%)을 AI로 생성하며, Supabase 신규 DB의 60% 이상, Neon의 80% 이상이 AI 도구·에이전트에 의해 생성됩니다. Bolt Cloud, Lovable Cloud, Replit 등 바이브 코딩 툴도 자체 내장 백엔드로 확장 중입니다.

트렌드 02

Postgres 80%

서버리스 Postgres 천하통일과 DB 브랜칭 표준화

에이전트가 프로덕션 데이터를 건드리지 않고 스키마와 데이터를 복제해 테스트할 수 있도록 500ms 이내 DB 브랜칭이 필수가 되었습니다. PlanetScale마저 2025년 9월 Postgres를 정식 출시했고, Supabase는 Vitess 팀 기반 Multigres와 OrioleDB로 대규모 확장을 준비하고 있습니다.

트렌드 03

에이전트당 1개 DB(One-DB-per-Agent)와 SQLite의 부활

에이전트 세션·사용자·작업마다 독립 DB를 수백만 개 단위로 띄우는 패턴이 부상하면서 경량 SQLite 가치가 재조명되었습니다. Turso는 Rust 재작성 엔진으로 단일 쓰기 병목을 돌파했고, Cloudflare D1과 함께 엣지·에이전트 메모리 DB 시장을 이끌고 있습니다.

트렌드 04

신규 격전지

에이전트 샌드박스(Sandboxes)와 서버리스 GPU의 폭발적 성장

LLM이 작성한 신뢰할 수 없는 코드를 안전하게 실행하는 Firecracker/gVisor 기반 마이크로VM 샌드박스가 격전지입니다. Modal Sandboxes 단독으로 ARR $3억을 기록했고, Vercel Sandbox, Cloudflare Sandboxes, GCP Cloud Run/GKE Agent Sandbox가 잇따라 출시되었습니다.

트렌드 05

MCP(Model Context Protocol)의 인프라 표준화

Supabase(Remote MCP + OAuth2 + Elicitations + Okta 연동), Vercel(Connect 1,000+ 커넥터 + MCP Events), GCP(Cloud Run·Workspace MCP 서버), AWS(Aurora DSQL MCP)까지 주요 플랫폼이 에이전트용 MCP 엔드포인트를 1급 기능으로 탑재했습니다.

트렌드 06

Active CPU 과금과 과금 상한(Billing Caps) 확산

AI 워크로드는 LLM 응답 대기 등 I/O 유휴 시간이 길어 기존 월 타임(Wall-time) 과금이 불리했습니다. Vercel Fluid Compute와 Cloudflare Sandboxes가 실제 CPU 실행 시간만 청구하는 Active CPU 과금을 도입했고, Modal은 초당 과금, Neon은 25% 단가 인하와 최소 과금 폐지를 단행했습니다. 폭주 에이전트 대비용 과금 상한도 보편화되고 있습니다.

트렌드 07

M&A 가속

데이터·보안·에이전트 레이어의 대형 M&A 통합

Databricks가 Neon을 약 $1B에 인수(2025.05)해 레이크하우스와 OLTP를 결합했고, Google은 멀티클라우드 보안 플랫폼 Wiz를 $32B에 인수(2026.03)했으며, Supabase는 Turso를 인수(2026.10)해 에이전트용 초경량 SQLite에서 대규모 Postgres까지 단일 파이프라인을 구축했습니다.

트렌드 08

오픈소스 생태계와 BYOC(Bring Your Own Cloud)의 결합

개발자·에이전트 신뢰를 얻는 오픈소스 코어(Supabase, Turso, Vercel AI SDK/eve) 위에, 규제·대기업 고객을 위한 자체 클라우드 실행(Vercel BYOC on AWS, Turso BYOC, Modal 20+ 멀티클라우드 풀링)을 제공하는 하이브리드 전략이 주류가 되었습니다.

4. 주요 플랫폼 심층 분석

Vercel — 프론트엔드 클라우드에서 'AI·에이전트 인프라'로 전환

정체성
Next.js 개발사 기반 풀스택 웹·AI 에이전트 실행 플랫폼
투자·성장
2025년 9월 Series F $3억 유치(기업가치 $9.3B, YoY 매출 +82%). 2026년 10월 Ship 기준 개발자 3배, 에이전트 트리거 배포 28배 증가
핵심 출시
AI Cloud(Fluid compute + Active CPU), AI SDK 7(주간 다운로드 1,600만+), Vercel Sandbox GA & Drives, Python GA, Daemons 베타, Workflows GA, 오픈소스 에이전트 프레임워크 eve, Vercel Connect GA, AWS BYOC GA
요금 구조
Hobby $0(월 100GB 전송, Active CPU 4시간) / Pro $20·월(Active CPU $0.128/hr, 프로비저닝 메모리 $0.0106/GB-hr, Sandbox 메모리 $0.0212/GB-hr) / Enterprise 맞춤
적합 대상
Next.js/React 팀, 풀스택 TypeScript·Python AI 앱, 프로덕션 에이전트 호스팅 팀

Vercel은 2025년 중반 AI Cloud를 기점으로 단순 프론트엔드 호스팅을 넘어 백엔드·Python(FastAPI/Flask/Django)·지속 실행 워커(Daemons)·격리 마이크로VM(Sandbox + 영구 스토리지 Drives)까지 통합했습니다. 특히 Fluid compute의 Active CPU 과금은 LLM 응답을 기다리는 동안 CPU 비용을 0으로 줄여 AI 추론·MCP 서버 운영비를 기존 서버리스 대비 최대 90%까지 절감합니다. 또한 v0의 비동기 API와 AI Gateway(US 전용 추론, Zero Data Retention, Token Pass)로 엔터프라이즈 제어권을 강화했습니다. 출처: https://vercel.com/blog/the-ai-cloud-a-unified-platform-for-ai-workloads , https://vercel.com/blog/vercel-ship-2026-recap

장점

  • 프론트엔드·API·Python·내구성 워크플로우·샌드박스·AI 게이트웨이의 압도적 통합 경험
  • Active CPU 과금으로 I/O 대기가 긴 에이전트·LLM 스트리밍 비용 대폭 절감
  • AWS BYOC GA 및 Zero Data Retention 지원으로 대기업 컴플라이언스 대응

단점

  • 고트래픽 이그레스·대용량 미디어·상시 GPU 추론(전용 GPU 클러스터)에는 비용 상승 주의 필요
  • 벤더 생태계(Next.js/Vercel Workflows 등) 결합도가 높아질 수 있음

Turso — Rust로 재작성한 동시 쓰기 SQLite, Supabase와 합류

정체성
Rust로 처음부터 재작성한 오픈소스 SQLite 엔진(구 Limbo) 및 디스크리스 클라우드 DB
M&A · 방향
2026년 10월 2일 Supabase가 Turso 인수 발표. Glauber Costa 창업자가 Supabase Head of Agentic Services로 합류. 기존 Turso Cloud·오픈소스 엔진 유지
핵심 기술
Turso 0.8에서 BEGIN CONCURRENT 기반 다중 쓰기 구현(64커넥션 9,500 TPS, 32커넥션 p99.9 2.4ms). io_uring 비동기 I/O, 네이티브 벡터 검색, Antithesis 기반 결정론적 시뮬레이션 테스트(DST), WAL-on-S3 디스크리스 아키텍처
요금 구조
Free $0(DB 100개, 5GB, 5억 행 읽기) / Developer $4.99·월(9GB, 25억 읽기) / Scaler $24.92·월(24GB, 1,000억 읽기) / Pro $416.58·월. 브랜치·PITR 추가 과금 없음
적합 대상
에이전트당 1개 DB(메모리·상태 저장), 멀티테넌트 SaaS, 로컬-퍼스트·임베디드 레플리카 앱

위 벤치마크(Turso 0.8 공식 블로그 기준)는 기존 SQLite의 고질적 약점이던 단일 쓰기 락(Single-writer lock)을 BEGIN CONCURRENT와 그룹 커밋으로 해결한 결과입니다. 64개 동시 연결에서 쓰기 처리량이 약 7배(9,500 TPS vs 1,370 TPS)로 늘었고, 32개 연결 p99.9 지연시간은 1.2초에서 2.4ms로 500배 단축되었습니다. 유휴 DB는 S3 스토리지 비용만 발생해 한 서버에서 수백만 개 DB를 운용할 수 있으며, Supabase 인수로 인해 에이전트가 만든 SQLite DB가 성장할 때 Postgres로 매끄럽게 승격되는 경로가 열렸습니다. 출처: https://turso.tech/blog/turso-0.8.0 , https://turso.tech/blog/turso-is-joining-supabase

장점

  • 파일처럼 가볍고 저렴하게 에이전트·테넌트당 수십만~수백만 개 DB 생성 가능
  • Rust 재작성 엔진의 비동기 I/O, 네이티브 벡터, 동시 쓰기 지원 및 로컬 임베디드 동기화
  • Supabase 생태계 합류로 향후 Postgres·Multigres로의 자연스러운 마이그레이션 기대

단점

  • 복잡한 대규모 관계형 조인·풍부한 Postgres 확장(PostGIS 등) 생태계와는 목적이 다름
  • Supabase와의 통합 아키텍처는 향후 순차 공개 예정

기타 2025~2026년 주목할 플랫폼

  • Cloudflare: 2026년 4월 Containers와 Sandboxes를 GA 출시하고 Active CPU 과금을 도입했습니다(Figma Make 등이 채택). Agents SDK(Durable Objects 기반 상태·웹소켓), D1(SQLite), Hyperdrive를 통한 PlanetScale Postgres 원클릭 연동까지 엣지 풀스택을 완성했습니다. (https://blog.cloudflare.com/sandbox-ga/)
  • PlanetScale & Convex: PlanetScale은 2025년 9월 PlanetScale for Postgres GA와 샤딩 솔루션 Neki를 내놓고 10월 $8천만($1B 가치) 투자를 받았습니다. Convex는 2025~2026년 총 $8,100만을 추가 조달하며 바이브 코딩 친화적 TypeScript 반응형 백엔드로 급부상했고, 내부 인프라는 PlanetScale Postgres를 사용합니다. (https://planetscale.com/blog/planetscale-for-postgres-is-generally-available)
  • Railway · Render · Fly.io: 하이퍼스케일러 대안 PaaS들도 대규모 자금을 확보했습니다. Railway(2026.01 Series B $1억)는 사용량 기반 과금과 10분 비활성 서버리스 슬립을, Render(2026.02 $1억 추가 투자, 가치 $1.5B)는 시트 요금 없는 예측 가능한 플랜($0/$25/$499)을, Fly.io는 기본료 없이 전 세계 초당 과금 마이크로VM을 제공합니다.
  • Netlify & AWS: Netlify는 AI 에이전트가 프로덕션 DB를 손상하지 못하도록 에이전트 전용 브랜치와 읽기 전용 프로덕션 API 가드레일을 내장한 Netlify Database를 선보였습니다. AWS는 서버리스 분산 SQL Aurora DSQL(2025.05 GA, MCP 지원)과 엔터프라이즈 에이전트 런타임 Bedrock AgentCore(2025.10 GA)로 대응하고 있습니다.
